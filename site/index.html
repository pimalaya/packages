Pimalaya packages

Signed APT and DNF repositories and a Homebrew tap for the Pimalaya command-line tools.

Each package holds the static binary of a GitHub release, with its man pages and shell completions, so one repository serves every Debian, Ubuntu, Fedora and RHEL version.
